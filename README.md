# Djawed Khalfaoui Academy

منصة أكاديمية خاصة — Next.js + Supabase، بتصميم "Dark Executive" الفاخر، RTL بالكامل.

---

## خطوات التشغيل (بالترتيب)

### 1. إنشاء مشروع Supabase
1. اذهب إلى https://supabase.com وأنشئ حسابًا ومشروعًا جديدًا (اختر منطقة قريبة، مثل أوروبا).
2. من **Project Settings → API** انسخ:
   - `Project URL`
   - `anon public` key
   - `service_role` key (سري، لا تشاركه أبدًا ولا ترفعه لأي مكان عام)

### 2. تشغيل قاعدة البيانات
1. من لوحة Supabase اذهب إلى **SQL Editor**.
2. افتح الملف `supabase/schema.sql` من هذا المشروع، انسخ محتواه بالكامل، والصقه في SQL Editor، ثم اضغط Run.
3. هذا سينشئ كل الجداول، قواعد الحماية (RLS)، ويضيف دورة "دورة السبونسور" تلقائيًا.

### 3. إنشاء حسابك كأدمن
بما أن التسجيل ليس عامًا (التسجيل يتم يدويًا فقط)، أول حساب — حسابك أنت — يُنشأ يدويًا من لوحة Supabase:

1. من **Authentication → Users** اضغط **Add user** وأدخل بريدك وكلمة مرور.
2. انسخ الـ `User UID` الذي تم إنشاؤه.
3. من **SQL Editor** نفّذ:
   ```sql
   insert into public.profiles (id, full_name, display_name, is_admin)
   values ('USER-UID-هنا', 'اسمك الكامل', 'Djawed Khalfaoui', true);
   ```

### 4. إعداد متغيرات البيئة محليًا
1. انسخ `.env.local.example` وأعد تسميته إلى `.env.local`.
2. املأ القيم الثلاث بما نسخته من Supabase في الخطوة 1.

### 5. التشغيل محليًا للتجربة
```bash
npm install
npm run dev
```
افتح http://localhost:3000 وسجّل دخولك بالحساب الذي أنشأته.

### 6. النشر (Deployment) على Vercel
1. ارفع هذا المجلد كمستودع على GitHub.
2. اذهب إلى https://vercel.com واستورد المستودع.
3. في إعدادات Environment Variables على Vercel، أضف نفس المتغيرات الثلاثة من `.env.local`.
4. اضغط Deploy.

### 7. الفيديو (Bunny Stream)
1. أنشئ حسابًا على https://bunny.net وفعّل خدمة Stream.
2. لكل فيديو ترفعه، ستحصل على `Video ID` — هذا هو ما تضعه في لوحة الإدارة عند إضافة الدرس.
3. رابط العرض المستخدم في الكود هو:
   `https://iframe.mediadelivery.net/embed/{LIBRARY_ID}/{VIDEO_ID}`
   يجب تعديل `components/LessonBody.tsx` لوضع `LIBRARY_ID` الخاص بك (متوفر من لوحة Bunny).

## كيف تضيف طالبًا جديدًا (سير العمل اليومي)

1. الطالب يدفع عبر BaridiMob أو CCP ويرسل لك إثبات الدفع.
2. تدخل إلى `/admin/students`.
3. تضغط "+ إضافة طالب"، تدخل الاسم، البريد، كلمة مرور مبدئية، وتختار الدورة.
4. ترسل للطالب بريده وكلمة المرور يدويًا (واتساب/رسالة).
5. الطالب يدخل من `/login` ويجد الدورة جاهزة له مباشرة.

## هيكل المشروع

```
app/
  login/            صفحة الدخول
  dashboard/         لوحة الطالب
  lesson/[id]/        صفحة الدرس
  community/          صفحة الأسئلة والأجوبة
  admin/              لوحة الإدارة (طلاب، دروس)
  api/admin/           نقاط API الخاصة بالإدارة (تعمل بصلاحيات service_role)
components/            مكونات React القابلة لإعادة الاستخدام
lib/supabase/           عملاء Supabase (متصفح، سيرفر، إدارة)
supabase/schema.sql       مخطط قاعدة البيانات الكامل
proxy.ts                حماية المسارات (يمنع الوصول غير المصرح به)
```

## ملاحظات أمنية مهمة

- كل الصلاحيات مفروضة على مستوى قاعدة البيانات (Row Level Security)، وليس فقط في الواجهة — حتى لو خمّن أحدهم رابط درس، لن يصل له إلا إذا كان مسجلاً فعليًا.
- مفتاح `service_role` يجب أن يبقى فقط في متغيرات البيئة على الخادم (Vercel)، ولا يجب أبدًا وضعه في كود يُرسل للمتصفح.
- تم فحص المشروع وتحديثه لأحدث نسخة آمنة من Next.js (16.3.3) بدون أي ثغرات معروفة (`npm audit` = 0 vulnerabilities) عند آخر بناء.

## ما لم يُبنَ بعد (اختياري لاحقًا)

- رفع الملفات مباشرة من لوحة الإدارة (حاليًا تضع رابط الملف يدويًا من Supabase Storage أو أي مكان آخر)
- دفع إلكتروني تلقائي
- إشعارات بريد إلكتروني أو واتساب
- شهادات إتمام
